How fast is a verified web server?

Rust (h5i-app), Go, TypeScript and Python serving the same APIs and PostgreSQL data. Tested with k6 at 1–256 concurrent clients after API conformance checks.

Overview

Requests/s at 16 clients. Longer bars mean higher throughput within a row. – = unmeasured.

Choose an application and scenario to compare throughput, latency and resource use.

Method

Fresh seed, 10 s warmup, 30 s measurement, mean of three repetitions. Compare implementations within the same application and scenario.

  • Servers, PostgreSQL and k6 use separate CPUs. Serial runs give each server 4 cores: 4 workers for Python, Node and Go; 4 Tokio threads for Rust.
  • Requests/s includes k6's graceful stop. Latencies are per-run percentiles; RSS is peak memory across the server process tree.
  • Login uses bcrypt cost 12, which dominates that scenario.
  • Single-host measurements. Scripts and CSV results: performance/.
